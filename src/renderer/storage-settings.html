Microsoft app registration settings (advanced)

AI WorkMate is a public desktop client using the Authorization Code + PKCE flow — it never uses or asks for a client secret. In Azure create an app registration as a public client/native application with redirect URI http://localhost and delegated permissions User.Read, Calendars.Read, and offline_access, then paste its Application (client) ID here. Tenant may be left as common.

Stored next to the app, never inside your data folder, and contains no secrets.

Google Cloud OAuth client settings (advanced)

AI WorkMate is a desktop (installed app) OAuth client using Authorization Code + PKCE — the client secret is optional and treated as non-confidential. In Google Cloud Console, enable the Google Calendar API, create an OAuth client of type Desktop app (any localhost redirect is accepted automatically), and paste its client ID here. Requested scopes are openid email profile and read-only calendar.readonly.

Stored next to the app, never inside your data folder.
